unkayOS 2.0

Sistema operacional web completo baseado em WebAssembly, Rust VFS com persistência OPFS, e componentes nativos do RDA Design System (§3.2 Identidade Cyan).

Kernel VFS unkay-wasm-vfs (Rust)
Engine Gráfica RDA DS Tokenized DOM
SSO Cluster Zitadel OIDC + PKCE
Browser Engine The Orb Adaptive Tiered
